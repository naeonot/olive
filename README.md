# Olive

A small, responsive starter website built with plain HTML, CSS, and JavaScript.

## Project structure

```
olive/
├── index.html
├── README.md
└── assets/
    ├── css/
    │   └── style.css
    ├── js/
    │   └── main.js
    └── images/
        └── .gitkeep
```

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Built with

- HTML5
- CSS3
- Vanilla JavaScript

No build step or package installation is required.
